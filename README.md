# PS2Manager
PS2Manager is a simple EXE application that currently doesn't have many features. It was built 100% with Python and is still under development.

PS2Manager can currently:

* View PS2 and PS1 BIN and ISO files.
* View ISO files that were originally BIN files but have been converted to ISO.
* Convert a USB drive to exFAT or FAT32 while safely preserving all existing files.
* Check the structure of your USB drive for OPL (Open PS2 Loader).

There will be many updates in the future, bringing new features and improvements. Currently, PS2Manager is only available for Windows, but more updates and platform support may be added in the future.
