# PS2Manager — All-in-One PS2 Toolkit for Windows

PS2Manager is an all-in-one Windows application designed to bring together a wide range of tools and utilities for PlayStation 2 users.

The project was created to simplify PS2 game management, storage management, disc operations, emulation, homebrew management, and various other tasks through a single centralized interface.

Instead of relying on multiple separate applications, PS2Manager aims to provide a convenient environment for managing different aspects of the PlayStation 2 ecosystem.

## Main Features

### PCSX2 Emulator
- Integrated access to the PCSX2 emulator.
- Tools for testing and working with PlayStation 2 games on PC.

### OPL Apps & Homebrew
- Management of applications and homebrew content for Open PS2 Loader (OPL).
- Support for working with OPL-related files.

### ISO Management
- Extract files from PS2 ISO images.
- Repack extracted files into ISO images.
- Convert and manage supported disc image formats.
- Create and manage ZSO compressed images.
- Fast and Ultra compression modes.
- Support for modifying ISO images using XDelta patches.
- Remove region restrictions from supported ISO images.
- Convert PS1 BIN images to ISO.

### Game Installation & USB Management
- Install PS2 games directly to USB storage devices.
- OPL-compatible `CD/` and `DVD/` directory structures.
- USBUtil integration and ISO splitting for FAT32 devices.
- Batch installation of multiple games.
- Automatic game cover downloading and linking.
- Real-time installation speed and progress monitoring.

### APA HDD Management
- Browse PlayStation 2 APA-formatted hard drives.
- Extract supported files and partitions.
- Create complete `.img` disk images.
- Work with PS2 HDD storage structures.

### Disc Tools
- DVD/CD ripping.
- Physical DVD and CD burning.
- Automatic optical drive detection.
- Multiple selectable burning speeds.
- Disc operation monitoring.

### Disc Analyzer
- Analyze disc image information.
- Inspect supported PlayStation disc formats.

### OPL Cheat Management
- Automatic creation of OPL `.cht` cheat files.
- Basic cheat file generation and management.

### Drive Management
- Clone drives.
- Format storage devices.
- Migrate data between drives.
- Manage USB storage devices.

### Settings & Customization
- Application configuration and preferences.
- Language selection.
- Dynamic interface translations without restarting the application.

## Language Support

PS2Manager currently supports six languages:

- Brazilian Portuguese (PT_BR)
- European Portuguese (PT)
- English (EN)
- Spanish (ES)
- Russian (RU)
- Japanese (JA)

All supported languages can be switched instantly through the application settings.

## Windows Compatibility

PS2Manager supports multiple Windows versions and system architectures.

- Windows 7 — 32-bit and 64-bit.
- Windows 8.1 — 32-bit and 64-bit.
- Windows 10 — 64-bit.
- Windows 11 — 64-bit.

Compatibility may vary depending on the specific feature and system configuration.

## Development

PS2Manager is an actively developed project. New tools, improvements, bug fixes, and compatibility updates are continuously being introduced.

Some features may still be experimental or under development, and certain operations may have limitations depending on the connected hardware and storage device.

The goal is to keep expanding PS2Manager into a comprehensive toolkit for PlayStation 2 users.
